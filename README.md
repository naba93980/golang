## Golang

A collection of Go programming concepts covering language fundamentals, core concepts, concurrency, and web development.


### Topics Covered

- **Go Fundamentals:** Variables, data types, user input, and type conversion
- **Data Structures:** Arrays, slices, maps, and structs
- **Control Flow:** If-else statements, switch cases, and loops
- **Functions & Methods:** Function declarations, methods, and deferred execution (`defer`)
- **Pointers & Interfaces:** Pointers, interfaces, and Go's type system
- **File Handling:** File operations and reading/writing data
- **Concurrency:** Goroutines and synchronization using WaitGroups
- **Go Modules:** Module initialization and dependency management
- **Web Programming:** Web requests, URL handling, and HTTP communication
- **JSON Handling:** Creating and consuming JSON data

### Getting Started

**Prerequisites:** Go (Golang) installed on your system.

1. Clone the repository:

   ```bash
   git clone https://github.com/naba93980/golang.git
   ```

2. Navigate to any individual example directory:

   ```bash
   cd golang/mygolang-lco/01hello
   ```

3. Run the example:

   ```bash
   go run main.go
   ```

4. Explore other examples by navigating to their respective directories. Each tutorial module contains its own `go.mod` file.

### Purpose

A hands-on learning repository for building a foundation in Go programming, progressing from basic language constructs to concurrency, Go modules, and HTTP-based web programming.
